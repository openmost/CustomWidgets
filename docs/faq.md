## FAQ

__How to install this plugin?__

This plugin is available in the official Matomo Marketplace. Install it the same way as other plugins:

- Go to the administration panel
- Open the Marketplace section and select "Plugins"
- Search for "**CustomWidgets**", install and activate the plugin
- Go to __Administration > System > General settings__, section __CustomWidgets__, to set the title and the content of the widget

__Who can edit the widget?__

Only super users can edit the widget, from the General settings. Every user can add it to their dashboards.

__Can I create several widgets?__

Version 5.x of the plugin provides one custom widget. The Matomo 6 version of the plugin supports unlimited widgets, managed from a dedicated page.

__Why is my iframe not displayed?__

Content loaded from another domain is blocked by the Matomo Content Security Policy. YouTube and YouTube no-cookie iframes are allowed by the plugin.

__Is the content of the widget filtered?__

No, the HTML is displayed as it is written, so only add content you trust.

__How can I contribute to this plugin?__

Open an issue or a pull request on [GitHub](https://github.com/openmost/CustomWidgets), or contact us at ronan@openmost.com.

__How long will this plugin be maintained?__

As long as possible. We use Matomo and this plugin on many projects every day, so issues are fixed as fast as possible.
