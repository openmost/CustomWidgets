## Documentation

Add custom content, such as text and custom HTML code, to your dashboards with a dedicated widget.
Share internal news, useful links, videos, iframes or any content with your team.

### Configure the widget

1. Go to __Administration > System > General settings__, section __CustomWidgets__.
2. Enter the title of the widget and the content to display (text and HTML).
3. Save the settings.

### Add the widget to a dashboard

Open a dashboard, click on __Dashboard__, then __Widgets__ and select the widget in the __Custom Widget__ category.

### Display external content

YouTube and YouTube no-cookie iframes are allowed by the Matomo Content Security Policy, so you can embed a video right away:

```html
<iframe width="100%" height="315" src="https://www.youtube-nocookie.com/embed/VIDEO_ID" allowfullscreen></iframe>
```

Iframes, images, videos, SVG and canvas elements never overflow the widget width.
